# Godot 4.7 → Foundry Port Catalog & Pipeline

**Date:** 2026-07-07
**Status:** In progress
**Staging branch:** `feature/godot-4.7-port` (off `origin/develop`)
**Upstream range:** `4.6.3-stable..4.7-stable` (Foundry is based on 4.6.3; `4.6.3-stable` is a verified clean ancestor of `develop`, so `cherry-pick -x` is viable)

## Goal

Port as much valuable 4.7 functionality and bugfixes into Foundry as is compatible with
the fork, batching the clear wins onto a single staging branch. Explicitly **out of scope:**
the Asset Store, and mechanical porting of areas the fork has rewritten (GDScript→Foundry
Script, the editor script-editor/workspace surfaces) — those are cataloged and flagged for
manual review, not auto-ported.

## Classification rules (precedence order)

A PR is routed by the set of files it changes (`git diff --name-only <merge>^1 <merge>`):

1. **dep-bump** — every path under `thirdparty/`.
2. **docs** — every path under `doc/classes/`.
3. **skip-assetstore** — any path contains `asset_library`.
4. **manual-flag** — any path under `modules/gdscript/`, `editor/script/`, or matching
   `editor/plugins/script_*` (the fork's diverged surfaces).
5. **candidate** — everything else; tagged with its dominant subsystem for fan-out.

## Pipeline

### §1 Setup — DONE
`godot` remote added, `4.6.3-stable`/`4.7-stable` fetched, ancestry verified, staging
worktree created at `.worktrees/godot-4.7-port`.

### §2 Mechanical classification — DONE
`docs/superpowers/specs/godot-4.7-port/classify.py` emits
`docs/superpowers/specs/godot-4.7-port/catalog.json`: one record per PR (1651 total) with
`sha`, `pr`, `title`, `bucket`, `subsystem`, `nfiles`.

### §3 Judgment triage (parallel subagents)
Fan out one subagent per subsystem over the `candidate` set. Each reads the PR title +
diffstat + touched files and assigns:

- **decision:** `port-now` (self-contained bugfix or low-risk feature), `port-later`
  (valuable but sprawling / risky), or `skip` (irrelevant to the fork, e.g. mono/C#, CI-only,
  web platform we don't ship).
- **kind:** `bugfix` | `feature` | `refactor` | `perf` | `platform`.
- **risk:** conflict likelihood against fork divergence (`low`/`med`/`high`).
- **rationale:** one line.

Godot's official 4.7 release notes are cross-referenced so no headline feature is silently
dropped. Bugfixes with `low` risk are the safest and highest-priority ports.

### §4 Porting mechanics
For each `port-now` PR, on the staging branch:

```
git cherry-pick -x -m 1 <merge-sha>
```

`-x` records the upstream SHA for traceability; `-m 1` takes the PR as a single squashed
delta against mainline. Conflict policy:

- Trivial/mechanical conflict → resolve and keep.
- Conflict that exposes hidden fork divergence → abort the pick, downgrade the PR to
  `manual-flag` in the catalog, move on. **Never force a messy port into the batch.**

Thirdparty deps (`dep-bump`) are not cherry-picked commit-by-commit; instead the vendored
directory is updated to match 4.7's version (and the corresponding `SCsub`/`thirdparty.md`),
one dependency at a time, each validated by a build.

### §5 Validation
Build with `python3 scripts/agent_build.py` (CI-strict `dev_mode`) and run the relevant test
slice after each coherent batch — not per-commit. The full suite
(`--headless test run`, prefixed `DISPLAY=:1` for GUI-dependent tests) gates the branch
before it is considered mergeable.

### §6 State tracking & resumability
`docs/superpowers/specs/godot-4.7-port/catalog.json` is the source of truth and is updated per PR with a `state` field: `ported`
(+ resulting local SHA), `flagged`, `skipped`, or `conflicted`. Because state is persisted,
the effort is resumable across sessions — a later run picks up the untouched candidates.

## Deliverables

1. This catalog doc + `catalog.json` (living state).
2. The `feature/godot-4.7-port` staging branch with clear-win ports cherry-picked, building
   green and passing the relevant test slices.

## Non-goals

- Asset Store (any form).
- Mechanical GDScript→Foundry Script porting; diverged editor script/workspace ports.
- `doc/classes` sync (deferred; heavy rebrand collision, low functional value).
- C#/mono, and platforms/features the fork does not ship (flagged `skip` during triage).
